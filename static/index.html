12 人预女猎白 · 有警徽 · 屠边
一局如何进行

夜间行动 → 首日竞选警长 → 公布死亡 → 按序发言 → 放逐投票 → 遗言与技能 → 下一个夜晚。

你的身份

预言家每夜查一位未查过的其他存活玩家；女巫解毒各一次，每夜只能一药，首夜可自救；猎人死亡可开枪，被毒无法开枪；白痴首度被放逐免死，失去投票权。平民用发言和投票找狼，狼人夜间商议击杀、白天隐藏身份。

警长与平票

上警 → 演说 → 退水 → 警下投票；仅一候选人自动当选。警长白天 1.5 票，选择发言方向、最后发言；死后可移交或撕徽。平票者 PK，其他有票玩家再投，再平无人出局。允许弃票，不能投自己。

出局以后

首夜死亡和白天放逐有遗言；后续夜死、自爆、被枪带走无遗言。你出局后可以继续旁观，结束时揭晓全员身份。

怎样获胜

全部狼人出局，好人获胜。全部神职或全部平民出局，狼人获胜。夜间死亡仅公布座位，不公布真实死因。
